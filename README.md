QA Portfolio

Учебное портфолио по manual QA. Практика проходила на saucedemo.com — учебном сайте с намеренно встроенными багами.

Что внутри

test-cases/ — тест-кейсы с применением техник тест-дизайна:

Equivalence Partitioning и Boundary Value Analysis (поля "возраст", "email", "количество товара")
Decision Table Testing (правило скидки от суммы корзины и промокода)
State Transition Testing (переходы статуса заявки в поддержку)

bug-reports/ — реальные баги, найденные на saucedemo.com:

Отсутствующая кнопка оформления заказа
Смещённая иконка корзины
Формат

Тест-кейсы: Precondition / Steps / Expected Result Баг-репорты: Title / Steps to Reproduce / Expected Result / Actual Result / Severity / Priority / Environment
