State Transition Testing — статус заявки в поддержку
Карта разрешённых переходов
Новая → В работе
В работе → Решена, Новая
Решена → Закрыта
Закрыта → (никуда)
Тест-кейсы
TC_001 — переход "Новая → Закрыта", невалид
Precondition: специалист на странице с заявками, есть заявка со статусом «Новая»
Steps:
Открыть заявку
Нажать «Сменить статус»
Выбрать «Закрыта»
Expected Result: система выдаст ошибку («нельзя перевести заявку из статуса "Новая" в "Закрыта"»), статус заявки не меняется
TC_002 — переход "В работе → Решена", валид
Precondition: специалист на странице с заявками, есть заявка со статусом «В работе»
Steps:
Открыть эту заявку
Нажать «Сменить статус»
Выбрать «Решена»
Expected Result: статус заявки меняется на «Решена»
