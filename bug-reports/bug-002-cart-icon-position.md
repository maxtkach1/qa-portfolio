Bug Report

Title: Неправильное положение иконки корзины (problem_user)

Steps to Reproduce:

Залогиниться под problem_user
Открыть каталог товаров
Добавить один или несколько товаров в корзину
Перейти в корзину (клик по иконке корзины вверху)
Вернуться обратно на страницу товаров

Expected Result: иконка корзины находится в положенном месте (верхний правый угол)

Actual Result: иконка появляется в середине страницы

Severity: Minor (визуальный баг, не блокирует функциональность)

Priority: Medium

Environment: Chrome, Windows 10, login: problem_user
